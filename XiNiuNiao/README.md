# Visualization and Analysis / 可视化与分析

## 中文说明

本目录包含论文实验中使用的可视化、误差分析和图表生成脚本。主要功能包括重建结果可视化、轨迹图、鼠标点击检测、SOTA 对比图和系统精度统计。

## English

This directory contains visualization, analysis, and plotting scripts used for the experiments. It includes reconstructed-pose viewers, trajectory plotting, mouse-click detection, SOTA comparison figures, and precision evaluation.

## 子目录 / Subdirectories

- `可视化/`: ground-truth/prediction pose visualization and trajectory analysis.
- `可视化/mouse/`: mouse-click micro-motion detection and playback tools.
- `sota/`: self-precision evaluation utilities.

`*.csv`, `*.txt`, and generated figures are ignored by Git. Prepare local exported inference files before running the visualization tools.
