# SOTA and Precision Evaluation / 对比方法与精度评估

## 中文说明

本目录包含用于系统自身精度评估和对比图生成的辅助脚本。

```text
evaluate_glove_self_precision.py   evaluate repeated measurements/self precision
```

根目录下的 `sota制图.py` 用于绘制不同手部位姿估计系统的对比散点图。

## English

This directory contains helper scripts for system precision evaluation and comparison-figure generation. The top-level `sota制图.py` script creates comparison plots for representative hand/fingertip pose-estimation systems.
